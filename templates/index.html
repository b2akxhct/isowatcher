Proxmox Sync
Synchronisation via SSH → script bash sur Unraid
ℹ Architecture SSH — Tout étant sur CIFS/SMB, les symlinks ne peuvent pas être créés depuis Docker (Errno 95). ISOWatcher déclenche sync_symlinks.sh directement sur Unraid via SSH. Unraid crée les liens sur son filesystem XFS natif → Proxmox les voit via son montage CIFS.
🔑 Configuration SSH (connexion vers Unraid)
✓ Clé publique générée — Copiez cette clé dans /root/.ssh/authorized_keys sur Unraid :
Commande rapide : ssh root@UNRAID_IP "mkdir -p ~/.ssh && echo '$(cat /data/ssh/id_rsa.pub)' >> ~/.ssh/authorized_keys"

Le scan parcourt récursivement le dossier /data/isos à la recherche de fichiers .iso. Chaque fichier est analysé : les ISO reconnues sont importées automatiquement avec leur checksum SHA-256. Guide d'ajout
Comment ajouter et configurer une nouvelle distribution
1

Comprendre les deux types de source

ISOWatcher supporte deux modes pour trouver et télécharger les ISOs :

ModeDescriptionQuand l'utiliser
Direct (URL)Scraping d'une page + URL de téléchargement avec placeholder {version}Linux, BSD, tout OS avec FTP public
rg-adguardNavigation automatique sur files.rg-adguard.net via UUIDWindows uniquement (Server, 10, 11)
2

Ajouter une distribution Linux (mode Direct)

Pour chaque distribution, vous avez besoin de 3 informations :

ChampDescriptionExemple (Fedora)
URL de vérificationPage contenant le numéro de versionhttps://dl.fedoraproject.org/pub/fedora/linux/releases/
Regex patternExpression pour extraire la version (groupe 1)href="(\d{2})/?"
Template URLURL de téléchargement avec {version}https://dl.fedoraproject.org/pub/fedora/linux/releases/{version}/Server/x86_64/iso/Fedora-Server-dvd-x86_64-{version}-1.1.iso

Le placeholder {version} sera remplacé automatiquement par la version détectée.

3

Exemples de configurations prêtes à l'emploi

Linux Mint (dernière LTS)

URL vérif : https://linuxmint.com/download.php
Regex     : href=".*?/linuxmint-(\d+\.\d+)-cinnamon-64bit\.iso"
Template  : https://mirrors.edge.kernel.org/linuxmint/stable/{version}/linuxmint-{version}-cinnamon-64bit.iso

Rocky Linux

URL vérif : https://dl.rockylinux.org/pub/rocky/
Regex     : href="(\d+\.\d+)/?"
Template  : https://dl.rockylinux.org/pub/rocky/{version}/isos/x86_64/Rocky-{version}-x86_64-minimal.iso

AlmaLinux

URL vérif : https://repo.almalinux.org/almalinux/
Regex     : href="(\d+\.\d+)/?"
Template  : https://repo.almalinux.org/almalinux/{version}/isos/x86_64/AlmaLinux-{version}-x86_64-minimal.iso

openSUSE Leap

URL vérif : https://download.opensuse.org/distribution/leap/
Regex     : href="(\d+\.\d+)/?"
Template  : https://download.opensuse.org/distribution/leap/{version}/iso/openSUSE-Leap-{version}-DVD-x86_64.iso

Kali Linux

URL vérif : https://cdimage.kali.org/kali-weekly/
Regex     : href="kali-linux-(\d{4}\.\d)-installer-amd64\.iso"
Template  : https://cdimage.kali.org/kali-weekly/kali-linux-{version}-installer-amd64.iso
4

Ajouter une source Windows (mode rg-adguard)

Dans le formulaire d'ajout, sélectionnez Source : rg-adguard, puis choisissez le slug dans la liste :

SlugDistribution
windows-server-2025Windows Server 2025
windows-server-2022Windows Server 2022
windows-server-2019Windows Server 2019
windows-11Windows 11
windows-10Windows 10

Les checksums SHA-256 et MD5 sont récupérés et vérifiés automatiquement depuis la page rg-adguard.

5

Tester votre configuration

Après avoir ajouté une distribution :

  1. Allez dans Distributions
  2. Cliquez sur ⟳ Check sur votre nouvelle distro
  3. Une notification indique la version détectée
  4. Si la version est correcte, cliquez ↓ Manuel pour tester un téléchargement
  5. Suivez la progression dans En cours
6

Trouver l'URL de téléchargement pour n'importe quelle distro

Méthode universelle pour trouver les bonnes URLs :

  1. Allez sur la page de téléchargement officielle de la distro
  2. Clic droit sur le lien de téléchargement de l'ISO → Copier l'adresse du lien
  3. Repérez le numéro de version dans l'URL → c'est votre placeholder {version}
  4. Remplacez le numéro par {version} pour obtenir le template
  5. Pour l'URL de vérification, prenez la page qui liste les versions (souvent le répertoire parent sur le FTP)

Exemple : https://example.com/iso/ubuntu-24.04-server.iso → template : https://example.com/iso/ubuntu-{version}-server.iso
